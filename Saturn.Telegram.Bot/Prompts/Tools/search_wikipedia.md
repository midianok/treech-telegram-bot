Поиск по Википедии. Возвращает вводные части до 3 найденных статей. Обязательно используй, когда вопрос касается проверяемых фактов: дат, исторических событий, биографий, чисел, географии, определений — вместо ответа по памяти. Не используй для болтовни, мнений и шуток.

## query

Короткий поисковый запрос из ключевых слов, например «Крещение Руси» или «Гагарин полёт»

## language

Код языка Википедии: ru (по умолчанию) или en для тем, которые лучше описаны в английской Википедии
