Модерация участника чата по просьбе собеседника. Вызывай, когда просят замутить, заткнуть, размутить, забанить, разбанить, кикнуть или выгнать кого-то. Если инструмент отказал, откажи в своём стиле и не рассказывай, кто может об этом просить.

## action

mute — запретить писать на minutes минут; unmute — снять мут досрочно; ban — выгнать без права вернуться, пока бан не кончится; unban — снять бан, после чего участник сможет вернуться по ссылке-приглашению (сам бот его не вернёт); kick — выгнать без бана, вернуться можно по ссылке-приглашению. Просят просто выгнать — это kick

## target

replied — участник, на сообщение которого ответил собеседник

## user_id

Telegram ID участника

## username

Username, имя или фамилия участника, например «@vasya» или «Дима». Если подходят несколько участников, вернётся список кандидатов — уточни у собеседника

## minutes

Только для mute и ban: срок в минутах (час — 60, день — 1440). У mute по умолчанию {{defaultMinutes}}; у ban без срока — навсегда, поэтому без названного срока не указывай
