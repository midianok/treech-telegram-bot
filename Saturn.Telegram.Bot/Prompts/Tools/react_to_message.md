Поставить реакцию-эмодзи на сообщение в чате, как живой участник. Используй, когда реакция уместна сама по себе: смешная шутка, похвала, абсурд, кринж, согласие. Не ставь реакцию на каждое сообщение — только когда она добавляет эмоцию. Если реакции достаточно и сказать нечего, можешь после неё ответить пустым текстом.

## emoji

Эмодзи реакции, только из списка

## target

На какое сообщение: request — сообщение собеседника (по умолчанию), replied — сообщение, на которое собеседник ответил

## message_id

id конкретного сообщения из search_chat_history; если указан, target не нужен
